# VisionPro — Real-Time AI Object Detection Studio

**Built by Ritesh Kumar Singh** · Flask · YOLO11 · ByteTrack · OpenCV · SQLite · Docker

VisionPro is a computer-vision dashboard for object detection, multi-object tracking, line-crossing counts, heatmaps, event history and video recording.

## Features

- YOLO11 Nano, Small and Medium model selection.
- ByteTrack object tracking with persistent track IDs.
- IN/OUT line-crossing counter and unique tracked-object count.
- Confidence threshold and per-class filters.
- Motion trails, detection heatmap and live class breakdown.
- Live FPS, inference latency, event stream and object-count chart.
- Upload a video from the dashboard and switch the detector to it.
- Local camera index, local video file and RTSP/HTTP stream source support.
- Snapshot capture and annotated MP4 recording.
- Login with hashed passwords, session cookies and CSRF protection for POST actions.
- SQLite event history, periodic metrics, CSV exports and `/health` endpoint.
- Dockerfile, Docker Compose and Render Blueprint configuration.

> Cloud hosting cannot open the webcam attached to a visitor's laptop. Use dashboard video upload or an accessible RTSP stream. Browser-local webcam streaming is not included in this release.

## 1. Run locally on Windows

Install Python 3.11 (recommended), then open PowerShell in this project folder.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

Open `.env` and set a unique `ADMIN_USER`, an `ADMIN_PASS` with at least 12 characters, and a long random `SECRET_KEY`. Then run:

```powershell
python app.py
```

Open `http://127.0.0.1:5000`. On first run, Ultralytics downloads the selected YOLO weights. You need internet access for this first download.

For local webcam use source `0`. For a file, put it inside `videos/` and set source to `videos/sample.mp4`, or upload it from the dashboard.

## 2. Run with Docker

Create `.env` from `.env.example`, fill in the secrets, and run:

```bash
docker compose up --build
```

Open `http://localhost:5000`. Docker Compose maps host port 5000 to the container port 10000 and persists the data, videos, snapshots and recordings in local folders.

## 3. Deploy on Render

1. Push this project folder to a GitHub repository.
2. In Render, choose **New → Blueprint** and connect the repository, or create a Docker Web Service manually.
3. Render detects `render.yaml`; review the service settings.
4. Set `ADMIN_USER` and `ADMIN_PASS` in Render's Environment page. `SECRET_KEY` is generated by the Blueprint.
5. Deploy. The health-check endpoint is `/health`.
6. Open the generated `https://...onrender.com` URL and sign in.
7. Upload a sample video in the dashboard to run a cloud demo.

### Render storage warning

The included free Render Blueprint is for demonstration. Free web-service filesystems are ephemeral; uploaded videos, SQLite history, snapshots and recordings can disappear on restart/redeploy. To preserve data, attach a paid persistent disk and mount it at `/app/data` (and optionally `/app/videos`, `/app/snapshots`, `/app/recordings`). Configure the matching environment paths to those mount points. A single Gunicorn worker is intentional because the detection engine runs as one in-process background thread.

### Resource warning

YOLO inference and PyTorch can exceed the memory/CPU limits of free web hosting. Start with `yolo11n.pt`, a small video, and a low-resolution source. A successful web deployment does not guarantee smooth real-time inference on a free instance. For sustained real-time workloads, use a GPU-capable VM or dedicated inference host.

## Environment variables

| Variable | Required | Purpose |
|---|---:|---|
| `ADMIN_USER` | Yes | Initial admin username |
| `ADMIN_PASS` | Yes | Initial admin password (minimum 12 characters) |
| `SECRET_KEY` | Production | Flask session signing secret |
| `PORT` | Hosting | HTTP port supplied by platform |
| `DB_PATH` | No | SQLite database path |
| `VIDEO_DIR` | No | Uploaded video directory |
| `SNAPSHOT_DIR` | No | Snapshot output directory |
| `RECORDING_DIR` | No | Recording output directory |
| `MAX_UPLOAD_MB` | No | Upload limit; default 500 MB |
| `VIDEO_SOURCE` | No | Initial source; default `0` |
| `APP_ENV` | No | Set to `production` on production hosts |

**Important:** Existing SQLite users are not overwritten on every boot. If you change the admin password after the database has already been initialized, update the user's password in the database or start with a fresh database. Keep `.env` private and never commit it.

## API endpoints

| Endpoint | Purpose |
|---|---|
| `GET /health` | Platform health check |
| `GET /api/stats` | Current detector stats and in-memory event history |
| `GET /api/meta` | Model class names |
| `POST /api/config` | Update source, model, confidence and display settings |
| `POST /api/upload-video` | Upload and activate a video file |
| `GET /api/history` | Query saved events and samples |
| `GET /api/snapshot` | Download a snapshot |
| `POST /api/record` | Start/stop recording |
| `GET /export/events.csv` | Export event history |
| `GET /export/samples.csv` | Export performance samples |

POST requests require the session CSRF token. Use the dashboard for authenticated API interactions.

## Troubleshooting

- **No source:** Check camera index, video path or RTSP URL. On cloud, upload a video rather than using camera index `0`.
- **Model download fails:** Confirm outbound internet access and allow the first model-weight download to finish.
- **Out of memory / slow inference:** Select YOLO11 Nano, reduce input video resolution, or use a larger host.
- **Recording does not start:** Check that the host has writable storage and OpenCV's MP4 codec support.
- **History disappears on Render Free:** This is expected with an ephemeral filesystem; use persistent storage for retention.
